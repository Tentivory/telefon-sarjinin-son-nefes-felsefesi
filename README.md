# Telefon Şarjının Son Nefes Felsefesi

## Resmi Uyarı

Bu depo bir şaka değildir.  
Şaka gibi durması, şaka olduğu anlamına gelmez.  
Şaka olsaydı şarj yüzde ikiye düşerdi. Yüzde birdeyiz.

T.C. Şarj Yüzde Biri Üst Kurulu tarafından,  
pili tükenmek üzere olan cihazların **son söz hakkını**  
korumak üzere hazırlanmıştır.

## Ne Yapar?

Çalışır. Gerçekten çalışır. Bu bile yeterince resmi bir skandaldır.

```bash
python3 son_nefes.py
```

Çıktı:

- sahte bir şarj çubuğu (estetik değil, resmi)
- rastgele ama iddialı bir son söz
- üç maddelik vasiyet
- damgalı tutanak

Gizli denetim dipnotunu görmek isterseniz (istemeyin):

```bash
python3 son_nefes.py --itiraf
```

## Neden Var?

Çünkü:

1. Yüzde bir şarj, yüzde sıfırdan daha felsefidir.
2. Bildirim gelmezken düşünce gelir.
3. Şarj aleti her zaman diğer odadadır. Bu bir doğa yasasıdır.
4. Resmi evrak, pil ömründen uzundur.
